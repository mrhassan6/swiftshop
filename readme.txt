SwiftShop is an ultra-fast, mobile-first WooCommerce Block Theme (FSE) built for high conversions, zero layout shift (CLS), and modern block-based commerce.

== Description ==

SwiftShop is engineered for store owners and developers seeking maximum speed, flawless mobile user experience, and conversion-optimized e-commerce design. Built from the ground up for WordPress Full Site Editing (FSE) with theme.json v3, SwiftShop delivers:

* **Zero jQuery Dependencies:** 100% modern, lightweight Vanilla JavaScript (ES6+).
* **Core Web Vitals Optimized:** Zero layout shifts (CLS), fluid typography, and instantaneous load times.
* **WooCommerce Native Block Templates:** Full block templates for Single Products, Product Catalogs, Shop Archives, and Search.
* **Ajax Slide-Out Cart Drawer:** Accessible, smooth sliding mini-cart with instant item deletion and badge updates.
* **Conversion-Driven Block Patterns:**
  - Sticky Mobile "Add to Cart" bottom bar.
  - Interactive Free Shipping Progress Bar.
  - Reassuring Trust Badges & Secure Checkout icon strip.
* **Full Site Editing (FSE):** Customise your header, footer, archive templates, and product pages directly within the WordPress Site Editor.
* **Accessibility First:** Screen reader friendly, keyboard navigable, and WCAG 2.1 AA compliant focus states.

== Installation ==

1. In your WordPress admin dashboard, navigate to **Appearance > Themes**.
2. Click **Add New Theme**, then click **Upload Theme**.
3. Choose the `swiftshop.zip` file and click **Install Now**.
4. Click **Activate** to activate SwiftShop.
5. (Recommended) Ensure WooCommerce is installed and activated to unlock all store templates and conversion patterns.

== Frequently Asked Questions ==

= Does SwiftShop require any page builder? =
No. SwiftShop is a modern WordPress Block Theme (Full Site Editing). It uses the native WordPress Gutenberg Block Editor and WooCommerce Blocks for maximum speed and zero bloat.

= Does SwiftShop depend on jQuery? =
No. SwiftShop runs on lightweight modern Vanilla JavaScript (ES6+), drastically reducing script payload and eliminating render-blocking bottlenecks.

= Can I customize colors and typography? =
Yes. You can customize colors, spacing, and typography globally via **Appearance > Editor > Styles**.

= Is SwiftShop translation-ready? =
Yes. SwiftShop includes complete gettext localization support and is 100% translation ready with the `swiftshop` text domain.
